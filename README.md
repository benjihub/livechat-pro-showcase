# LiveChat Pro

A portfolio showcase of my work on a modern customer-support and live-chat platform.

> The production source repository is private because the project extends a licensed third-party support platform. This repository documents my implementation work without redistributing licensed source code.

## Overview

LiveChat Pro brings customer conversations, support tickets, live chat, automation and AI-assisted support into one operational interface.

My work on the platform has included extending and integrating features around messaging, support workflows, automation and administration.

## Features worked on

- Live customer chat and support workflows
- Agent and team messaging
- Shared inbox and ticket management
- AI-assisted support responses
- LiveChat widget integrations
- WhatsApp integration
- Telegram integration
- Real-time messaging and notifications
- Customer and agent management
- Affiliate and referral workflows
- Admin dashboards and operational tooling
- Support automation and conversation flows

## Technology

- Laravel / PHP
- React

- AI model integrations
- WhatsApp Cloud API
